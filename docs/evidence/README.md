# Evidence

This directory contains dated runtime evidence and benchmark reports.

Evidence documents record what was observed in a particular environment and time window. They are not timeless architecture specifications and must not be treated as proof that the current runtime is still healthy.

## Evidence rules

- Keep architecture, runbooks, and desired-state descriptions in their canonical docs.
- Put dated execution results here.
- State the environment, scenario, result, and evidence boundary.
- Distinguish static validation from live runtime verification.
- Do not rewrite a historical result to make it look current; add a new dated report when the scenario is revalidated.
